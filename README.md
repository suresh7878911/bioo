# Suresh Trading Lab

A responsive, dark-themed landing page for a personal market research and trading-process workspace.

## Current website
- Responsive navigation for desktop and mobile
- Introductory hero and illustrative chart preview
- Workspace overview for chart research, strategy development, and journaling
- A three-step research workflow
- Roadmap and risk disclaimer

## Run locally
Open `index.html` in any modern browser. No build step or package installation is required.

## Deployment
This is a static HTML website and can be deployed with GitHub Pages, Vercel, or another static hosting provider. Connect this repository and use the repository root as the project directory.

## Important
The chart is illustrative, not live market data. The site does not connect to a broker, place orders, or provide investment advice. Live market data and strategy modules should be added and tested separately.
